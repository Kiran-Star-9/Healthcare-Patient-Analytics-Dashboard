🎯 Project Objective

The objective of this project is to transform raw healthcare data into interactive dashboards that provide clear insights into hospital performance, patient appointments, satisfaction, demographics, and operational trends.

🔍 Key KPIs & Analysis

The dashboards include:

- 👥 Total Patients
- 📅 Patient Appointments
- ⏱️ Average Wait Time
- ⭐ Patient Satisfaction Score
- 🏥 Hospital & Department Performance
- 👨‍👩‍👧 Age Group Demographics
- ⚥ Gender Distribution
- 📈 Patient Visit Trends
- 📊 Appointment & Satisfaction Analysis

🛠️ Tools & Techniques

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning & Preparation
- Interactive Dashboard Design
- KPI Reporting

🚀 How to Use

1. Download "Healthcare Dashboard.xlsx".
2. Open the workbook in Microsoft Excel.
3. Use the interactive Slicers to filter the dashboards.
4. Explore hospital performance, appointments, patient satisfaction, demographics, and trends.
5. Use the KPI cards and charts for quick data analysis.
